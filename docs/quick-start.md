# 快速开始

## 创建大肥鱼

1. 打开站点的 Web 管理面板。按页面顺序验证用户名、验证邮箱并设置密码。站点采用邀请码注册时，先向站点管理员获取邀请码。
2. 登录后，在账号页填写大肥鱼要使用的 QQ 号、可以在私聊中指挥她的管理员 QQ 号，以及 DeepSeek API Key。每个站点账号可创建一只大肥鱼。
3. 使用刚填写的大肥鱼 QQ 账号扫码，在手机上确认登录。
4. 点击「启动大肥鱼」。B 站可按需在账号连接页配置，日常设置和运行状态位于「她的控制室」。

QQ 账号可能因自动化操作被平台风控、限制功能或封禁。请自行评估使用风险。

## 更换模型供应商

在「密钥与安全 → 模型凭据」选择供应商，填写相应的 API Key。自定义供应商还需要兼容 OpenAI Chat Completions 的公网 HTTPS API URL，可填写模型 ID。只填域名时会默认使用 `/v1`。保存后重新启动大肥鱼。 [供应商及 Harness 排查](harness.md)

在 Windows 上，仓库里的 `start.cmd` 显示服务器入口。直接调试代码的命令见 [本地开发](development.md)。
