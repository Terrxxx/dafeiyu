# 管理面板与自主能力更新（2026-10-28）

## 每日额度
设置「发布与额度」可独立启用 token 上限和人民币费用上限，任意一项达到即暂停模型请求、外部查询、消息和自主行为，北京时间每日零点恢复。精力、健康和睡眠的本地时钟继续运行。默认不开启限额；用量从本次部署开始记录，不回填过去消费。

费用只估算本实例收到的 API usage，计入缓存命中、未命中输入及输出，使用 DeepSeek 官方价格快照：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ （2026-10-28）。支持 flash/pro 的高低峰差异；2026 年节假日依据 https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html 。估算不是最终账单；单个正在执行的请求可能超过剩余额度。未知价格、缺失 usage 或异常重启导致用量不确定时，开启的限额会进入保护暂停。每日记录存于每用户目录 daily-usage.json，跨进程重启保留。

## 状态、存储与界面
情绪健康默认只读，设置开启编辑后接口才允许修改。精力、健康精确两位小数。图片最多 2000 张且总计不超过 1GiB，满额后禁止图片读取。存储页面仅展示文件名、AI 摘要与大小，可删除选中或清空；删除记录防止后台旧状态恢复图片元数据。

小数值设置紧凑排列，天气三个下拉框同一行；移除 QQ 连接开关。官方性格与行为示例在同一卡片切换，先预览再应用，行为示例追加至行为偏好段落。

## QQ、B站和逛店
QQ 个人资料、空间动态及评论读取，以及空间点赞、评论和回复均写入独立 QQ 足迹，不记录聊天。
B站新增自身关注、粉丝、站内通知、已有私信会话与消息读取，以及对已核验通知或消息的回复。站内信回复只允许对应来源目标，首轮建立基线，不批量回复旧消息。相关读取和操作记录于 B站足迹。平台内大肥鱼之间使用散列账号标识防止自动互聊，私密账号信息不共享。
开启匿名逛店后自主任务可搜索真实商品、决定是否分享至 QQ 或空间，并保存实际读取的商品图片；仍受 QQ 权限、睡眠和每日额度约束，不购买、不登录、不绕过验证码。

## 验证
206 项自动测试：205 通过，1 项跳过。独立临时用户浏览器验证 39 张截图，无脚本错误或移动端溢出。实际 Harness SDK、语音、浏览器及 B站登录只读验证通过；没有发送测试私信、评论或动态。

## 第二批更新：余额提醒、指向检测和用量分析

余额低于5元时，由运行中的大肥鱼向配置的 QQ 管理员私聊提醒，同一低余额区间每人一次，恢复至5元后再次降低可再提醒。只使用真实人民币余额，不转换美元、不调用模型。睡眠、日额度暂停或服务停止时不绕过静默规则，发送状态不明时不重发。

群聊保存真实 @ 和引用对象，明确对别人说话时直接跳过；群成员短期缓存检测平台注册同类及同名账号。多人同名而仅泛称大肥鱼时保守沉默，真实 @ 或引用自己时再判断。

管理员可统一启停组件。停用策略即时下发所有租户，在工具列表、执行和用户安装接口校验，同时保存用户关闭状态；重新开放后由用户自行启用。新实例立即继承策略。RSS、Windows应用继续不可开放。

情绪记忆与接话判断合并为一次内部请求，最近12条/5000字符上下文；聊天生成仍使用完整角色、权限、情绪与当前会话记忆。普通聊天按话题加载工具描述，后台保留全部授权能力。历史去掉重复身份包装，完整原话归档保留。缓存由模型服务管理，不承诺固定命中率：https://api-docs.deepseek.com/zh-cn/guides/kv_cache/ 。

累计、本小时、今日、本周 token 展示在生活概览，日与周按北京时间，周一起算。累计从已有最早日账本起算；小时、分类和缓存明细从此次更新开始，不伪造历史。明细保留90天，累计不随明细淘汰减少。按最近7天的活动成本和当前配置估算清醒每小时消耗，至少3轮活动样本、总体至少1小时观测。部分设置旁显示预计增加/减少，未知项目明确显示样本不足。

按最新更正，情绪、精力、健康为0至100，只有用户好感度为-100至100。旧负情绪归零，接口拒绝负值。新 MCP 组件本轮仅提出建议，没有安装。
