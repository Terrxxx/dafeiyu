# 管理控制台界面规范

本次保留原生 HTML / CSS / JavaScript 与既有主题变量，统一账号控制台、登录/注册、站点管理和大肥鱼控制室。

## 设计参考

- [Linear：2026 界面更新](https://linear.app/now/behind-the-latest-design-refresh)：降低导航视觉权重，统一标题与动作位置，控制信息密度
- [shadcn/ui：Dashboard](https://ui.shadcn.com/blocks?category=dashboard)：侧栏、内容区、紧凑控件和表格层级；仅参考布局，不增加 React/Tailwind 依赖
- [Vercel：Dashboard 导览](https://vercel.com/academy/optimize-your-vercel-account/tour-the-dashboard)：区分工作空间管理与实例内设置

## 约束

- 账号页使用固定224px侧栏、64px位置栏和32px内容留白；手机改为顶栏与横向导航
- 账号页分为实例概览、账号连接、密钥与安全；选项卡支持键盘方向键、Home、End，并保留URL片段
- 使用现有项目颜色变量，白色/深色画布为主，蓝色仅作链接与焦点强调
- 普通控件圆角6px，面板8px；主要按钮深浅反转，避免大面积彩色横幅与圆形胶囊
- 字体为系统字体，正文14/13px，标题24/20px，辅助12/11px；字重400/600
- 状态有文字，图标为同一套16px线性SVG；大肥鱼形象只作小尺寸品牌标记
- 支持浅色、暗黑、跟随系统；不为主题切换添加颜色过渡，避免短暂低对比度
- 身份、API Key、记忆、平台连接与运行机制不因视觉改造而改变

## 登录行为

未登录导航到受保护页面时返回302至 `/login?next=原地址`，登录后恢复站内目标地址。拒绝站外和反斜线跳转地址。正常网页API请求仍返回JSON 401；浏览器直接打开API地址时也会跳转登录。登录、注册、激活与必需静态资源可直接打开。

## React + Vite 工作空间（2026-10-28）

前端源码位于 frontend/，React 页面模块 App、Account、Panel、Admin，shared 提供表单、数据请求、主题和图表。React 管理全部页面状态，无 iframe 或旧脚本包裹。使用项目蓝/海军蓝语义变量、Lucide 图标与原生 CSS；支持浅色、暗黑和系统主题。统一侧栏、移动导航、工作空间卡片、生活概览、关系环图、分组设置、可编辑记忆及日志。宽屏填满侧栏后的可用宽度。

构建：npm --prefix frontend ci，然后 npm run build:web。生产构建在 frontend/dist，由现有管理服务同源提供 /console/assets/ 静态资源，不另开公网 Vite 服务。npm run dev:web 启动仅本机开发服务器，API 转发至13082；生产访问地址不变。源码不含用户密钥。

登录/注册/激活、账号连接、B站二维码、密钥和余额、站点邀请管理、控制室均沿用原有鉴权与接口。用户数据仍在 /opt/dafeiyu/data/{username}/。回滚时恢复备份 manager/server.js；旧前端源码保留但不再作为生产入口。


## 交互与权限增强
站内链接通过 history API 切换，保留页面外壳和主题，使用180ms轻量入场动画；减少动画偏好下关闭。配置状态采用语义绿/红。RSS/Windows卡片可见但禁用，后端也拒绝运行。用户关系分数可编辑，单独的用户情绪只能自然形成。自身情绪与虚拟健康支持-100至100，精力0至100、心率40至120，使用范围滑动条和带数字扇形图。
QQ设置合并消息节奏、空间权限和发布额度，语音单独分组。名单黑名单优先，白名单留空则不限；管理员私聊保留。好友审核默认拒绝，开启且填写好感门槛后仅对达标用户交AI审核。官方提示词示例仅填入编辑器，保存前不改角色。运行日志清空以持久时间分界隐藏旧日志，不删除独立业务审计与社交足迹。


## 居中布局与足迹详情
桌面主内容区域占侧栏以外空间的70%，居中；1200px以下88%，移动端满宽。卡片统一24px内边距/间距、8px圆角、双列等宽并对齐高度。组件分为已安装/未安装，开启状态为语义绿。官方提示词选择只更新右侧预览，显式应用才修改编辑器。设置按QQ、B站、自主生活开头，天气与日志置底。新增adminOnlyDialogue仅保留管理员私聊，底层名单与发送均执行。B站评论日志新增实际评论样本，发表评论关联已读视频BV；不为旧记录编造评论或额外发送查询。


## 黑白名单选择器与区级天气
私聊黑白名单来自自己的用户记忆列表；群聊来自当前绑定且核实登录的QQ，通过受限只读OneBot群列表动作取得，不提供任意OneBot执行。已选但不在列表的号码仍保留可取消，勾选黑/白之一会取消另一项。保存设置通过左下角悬浮按钮提交原表单，仍执行版本冲突检查与数值校验。
省市区数据为本地缓存的阿里云DataV.GeoAtlas区划及中心点，国家固定CN，区级缺失地区禁选。地区数据分包按需加载；服务端以区划码索引派生坐标，天气直接按所选区中心点查询。
余额由DeepSeek官方 /user/balance 提供，不是剩余token数量；网页自动每分钟更新，共用60秒缓存和并发请求，余额不足沿用停服机制。self_api_balance 工具只查询实例自己的APIKey，只能自主使用或供管理员私聊查询，普通用户与群聊不得获取余额。
