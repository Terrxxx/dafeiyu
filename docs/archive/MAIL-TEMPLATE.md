# 邮件内容设置

在站点管理 → 站点设置 → 邮件内容设置中编辑，保存站点设置后生效。已有站点自动提供示例模板，无需修改数据库。注册激活、旧用户绑定以及测试发信共用此模板；用途和按钮链接自动填入。

支持 HTML 源码、格式化编辑和隔离预览。格式化工具包含加粗、斜体、下划线、标题、段落、列表、居中、字号和验证按钮。富文本粘贴会先经服务端清理。邮件仅保留常用标签和行内样式，不支持脚本、表单、iframe 或 style 标签。预览不会载入外部图片。恢复示例仅修改草稿，仍须保存。

变量：{{site_name}}（发件人名称）、{{username}}、{{action_label}}、{{purpose}}、{{expires_hours}}、{{verification_url}}。HTML 必须包含 href="{{verification_url}}" 的链接；纯文本正文可留空自动生成，手动填写时也须保留验证链接变量。实际发信同时提供 HTML 和纯文本。模板中的变量值会做 HTML 转义。

测试发信使用已保存模板，显示测试用途和无效的示例链接，不产生激活令牌。真实邮件是否送达仍取决于 SMTP 配置；请保存后主动发送一封测试邮件确认。

## 邮箱登录与验证码模板

登录页支持用户名或邮箱加密码；输入邮箱后可选择邮箱验证码登录。验证码为6位数字，有效10分钟，每60秒可重新发送，同一邮箱或来源每小时最多请求5次，单次挑战最多尝试5次；重发即使旧码失效，成功后也不可复用。登录验证码仅以带服务密钥的摘要保存，不写日志，发送失败会立即失效。待激活、停用或不存在的账号不会收到登录码，接口统一提示。邮箱验证码成功也会确认邮箱归属，未激活账号仍须先完成原来的激活流程。

站点设置的邮件内容设置可分别选择“激活与绑定邮件”和“登录验证码邮件”。验证码模板的变量为 {{site_name}}、{{username}}、{{login_code}}、{{expires_minutes}}，HTML与非空纯文本均须保留{{login_code}}。已有配置自动使用新的验证码示例，不覆盖现有验证邮件模板。测试发信可选择类型；验证码测试邮件使用123456示例，不签发登录挑战。

注册页依次填写用户名（服务端检查重名）、邮箱、密码、确认密码，以及邀请码（按站点注册模式显示）。每步仅一个输入框，可返回修改，最终提交时服务端再次校验所有字段与注册策略。密码仅存于当前页面内存，不写入浏览器存储。
