# 功能与设置

## QQ 和 B 站

- QQ 支持私聊和群聊。大肥鱼会合并连续消息，再决定是否接话。她可以用文字、引用、@、表情包、图片或语音交流，也可以主动找人聊天。
- QQ 通过 NapCat / OneBot 11 连接。互动范围由聊天开关和黑白名单控制。只有配置的 QQ 管理员能在私聊中要求执行跨会话操作。
- QQ 空间支持读取、点赞、评论、回复评论和发布图文动态。B 站支持视频浏览、点赞、评论、收藏、关注、动态及站内消息处理。实际动作取决于登录状态、组件、权限与额度。
- 控制室可查看 QQ 和 B 站业务足迹，并按操作筛选。QQ 足迹与聊天记忆分别保存，B 站观看记录可在 B 站账号中查看。 [业务接口历史说明](archive/ACTIVITY-APIS.md)

## 记忆和自主生活

- 她会结合当前说话者和话题选取记忆。群聊和私聊共享对同一用户的认识，回复时保护私聊细节。睡眠整理会把日常记录加入每个用户的记忆清单，记忆概述可在面板只读查看。
- 聊天、浏览和天气会影响她的精力或情绪。睡眠期间停止回复和查询，醒来后可以查看积压的消息。她也能给自己安排任务或小睡。
- 控制室可以修改提示词、查看日程和记忆、管理组件，以及屏蔽用户或清除其记忆。

## 模型用量

生活概述显示每日 Tokens、请求次数和按供应商筛选的趋势。费用估算支持今天、最近 3 天、最近 7 天、最近 30 天及全部，按北京时间统计。「全部」汇总已保留的估算记录，缺少供应商标记的旧用量单独显示。 [模型用量和限额](harness.md)
